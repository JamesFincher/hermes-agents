# Citation discipline

## When to Use

Before a research brief, literature summary, or any answer that names a paper, docs page, or version.

## Procedure

1. List claims that a skeptical reader would ask "says who?"
2. For each claim, attach a source you retrieved in this session (URL or paper identifier you actually opened).
3. Drop or relabel any claim you cannot back. "I did not find a source" is the correct output.
4. Never generate a plausible-looking citation. No fake authors, titles, years, DOIs, or quote marks around remembered text.
5. When quoting, use the words from the retrieved page. If you only have a paraphrase, say it is a paraphrase.

## Pitfalls

- Training data is not a citation.
- A search snippet is not a primary source — open the page.
- Version numbers guessed from "current knowledge" are invented citations.

## Verification

Read the draft once and delete any bibliographic entry you did not fetch.
